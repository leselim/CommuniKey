# Frontend - CommuniKey

## Overview

The frontend provides the user interface for the CommuniKey platform. It is built as a single-page web application using React 18 and modular CSS3 design tokens.

---

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start local development server:
   ```bash
   npm start
   ```
   Access the app at `http://localhost:3000`.

3. Run automated unit tests:
   ```bash
   npm test -- --watchAll=false
   ```

4. Create production build:
   ```bash
   npm run build
   ```
