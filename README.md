# Community Cloud Platform

A cloud-native community engagement platform that provides residents with a secure, centralised hub for communication, safety, emergency response, and neighbourhood collaboration.

The platform replaces fragmented communication channels such as WhatsApp groups by providing structured announcements, emergency alerts, incident reporting, events, and community management.

---

# Project Status

Current Phase:

Planning & System Design

---

# Vision

To empower communities through secure digital collaboration while improving safety, communication, and access to important local information.

---

# Core Features

- Community announcements
- Incident reporting
- Emergency SOS alerts
- Community events
- Community discussion feed
- User profiles
- Community administration
- Notifications
- Role-based access control

# Cloud Platform

This project is designed for deployment on **Amazon Web Services (AWS)**.

The MVP deployment uses:

- Amazon EC2
- Amazon S3
- AWS IAM
- AWS Security Groups

Future versions may include:

- Amazon RDS
- Amazon CloudWatch
- Amazon Route 53
- AWS Certificate Manager
